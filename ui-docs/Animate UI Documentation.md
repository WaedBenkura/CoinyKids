# Animate UI Documentation

Animate UI is a distribution of animated React components built with Tailwind CSS and Framer Motion, based on the `shadcn/ui` model. It is **not a typical install-from-NPM library**; components are copied directly into your codebase.

## Installation

Animate UI components are installed by copying the source code into your project, similar to `shadcn/ui`.

1.  **Ensure you have a Next.js/React project** with Tailwind CSS and Framer Motion set up.
2.  **Copy the component's code** from the documentation page into your project's components directory.
