# Badtz UI Documentation

Badtz UI is a free, open-source React component library designed for building beautiful, high-converting landing pages, built on the `shadcn/ui` model.

## Installation

Badtz UI components are installed using the `shadcn/ui` CLI, referencing the component's JSON file directly.

1.  **Ensure you have `shadcn/ui` initialized** in your project.
2.  **Add a component** using the CLI command, replacing `[component-name-kebab-case]` with the desired component (e.g., `glowing-button`):

    ```bash
    pnpm dlx shadcn@latest add https://badtz-ui.com/r/[component-name-kebab-case].json
    # or using npm
    npx shadcn-ui@latest add https://badtz-ui.com/r/[component-name-kebab-case].json
    ```
