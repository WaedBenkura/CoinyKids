# Smooth UI Documentation

Smooth UI is a collection of beautifully designed components with smooth animations built with React, Tailwind CSS, and Framer Motion. It is an official `shadcn/ui` registry.

## Installation

Smooth UI components are installed using the `shadcn/ui` CLI with the `@smoothui` namespace.

1.  **Ensure you have `shadcn/ui` initialized** in your project.
2.  **Add a component** using the CLI command, replacing `[component-name-kebab-case]` with the desired component (e.g., `siri-orb`):

    ```bash
    pnpm dlx shadcn@latest add @smoothui/[component-name-kebab-case]
    # or using npm
    npx shadcn-ui@latest add @smoothui/[component-name-kebab-case]
    ```
