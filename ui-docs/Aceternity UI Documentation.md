# Aceternity UI Documentation

Aceternity UI is a collection of animated components built with Next.js, React, Tailwind CSS, and Framer Motion, following the `shadcn/ui` model.

## Installation

Aceternity UI components are installed by copying the source code into your project, similar to `shadcn/ui`.

1.  **Ensure you have a Next.js/React project** with Tailwind CSS and Framer Motion set up.
2.  **Add a component** by copying the source code from the documentation page into your project's components directory.
3.  **Ensure necessary utilities are added** (e.g., `cn` function, `tailwind.config.js` modifications) as per the library's setup guide.
